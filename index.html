Lembar Ringkasan Sintaks (Cheat Sheet)

Referensi cepat fungsi dan metode bawaan Python yang paling sering digunakan sehari-hari.

String & Slicing

s[start:stop:step] : Irisan karakter
s[::-1] : Membalik string
s.strip() : Hapus spasi ujung
s.split(",") : Pecah jadi list
",".join(list) : Gabung jadi string
f"{x:.2f}" : Format 2 desimal

Metode List

lst.append(x) : Tambah di akhir
lst.insert(i, x) : Sisip di index i
lst.pop(i) : Ambil & buang index i
lst.remove(val) : Hapus nilai pertama
lst.sort() : Urutkan in-place
len(lst) : Jumlah elemen

Dictionary (Key-Value)

d.get(k, default) : Ambil aman tanpa crash
d.keys() : Kumpulan kunci
d.values() : Kumpulan nilai
d.items() : Pasangan (k, v)
d.update(other) : Gabungkan kamus

Kontrol & Built-in

range(a, b, step) : Deret bilangan
enumerate(seq) : Pasangan (index, nilai)
zip(a, b) : Pasangan paralel
isinstance(x, int) : Cek tipe data
with open(...) as f: : Baca/tulis file aman
